# openapptnz.com

## translation files

This is the translation page for https://openapptnz.com/find.php.

Many translations are using data from https://github.com/GlycoProduction/EmoteLab-localization.

Please Take a copy of the CSV or ODS to use in the spreadsheet software of your choice. Fill out your language translations, email it to info@openapptnz.com or create a Pull Request and submit your language changes here, do not change the original files append the language code for your region, e.g. fr for french.

Please be respectful as this is a voluntary project.
