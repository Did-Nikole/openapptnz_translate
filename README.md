# openapptnz.com

## translation files

Please be respectful as this is a voluntary project.

Translations for textures must match Emotelab translations (either for an animation or part). 

I will be accepting change suggestions to the English options we will be translating from. Changes for other languages that are adding context can also be submitted however the Emotelab Translation will take priority and the added context will be shown in [] brackets at the right side of the Emotelab version. All suggestions will only be considered as long as the corresponding regions name file is included with the proposed change.

Due to manual entry of data, errors may have occurred. Please let me know if you spot any.

Full translation revisions will be rare as this process is not automated and is extremely time consuming. Thank you for your understanding.
