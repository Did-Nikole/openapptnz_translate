# openapptnz.com

## translation files

All translations that were available on the Emotelab community translations page as of August 2026 were used (manually added) to translate OpenApptNZ Emotelab Texture Search Pages. Translations for textures must match Emotelab translations (either for an animation or part). Additional context is allowed to be added alongside the texture in app name (to be placed with-in brackets as this text is for example) for easier search-ability. Due to manual entry of data errors may have occurred. Suggestions for changes to English entries (using en entries from Emotelab Community translations) are accepted as long as the corresponding regions name file is included with the proposed change.

Please be respectful as this is a voluntary project.
